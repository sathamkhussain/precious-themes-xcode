
#Precious Themes for Xcode
A port of the Precious Themes JetBrains plugin for Xcode, featuring all four carefully crafted color variants designed for long coding sessions with reduced eye strain.
Themes Included

Precious Dark Eleven — Pure near-black background with neutral syntax colors
Precious Dark Fifteen — Warm dark background with a subtle brown tint
Precious Light Warm — Cream/parchment background with earthy, warm tones
Precious Light White — Cool near-white background with crisp, cool syntax colors

#Installation

Download the .xccolortheme file(s) from this repository
Copy them to ~/Library/Developer/Xcode/UserData/FontAndColorThemes/ (create the folder if it doesn't exist)
Restart Xcode
Go to Xcode → Settings → Themes and select your preferred variant
